# 写作蓝图：七段怎么落笔

总篇幅 6000–9000 字（中文），配 2–4 张图、5–9 个节点卡。宁可少写一个节点，也不要写空。

| 段 | 建议字数 | 核心任务 |
|---|---|---|
| 导语 + 1 现状 | 1200–1600 | 让读者 30 秒知道「它现在怎么样、为什么值得写」 |
| 2 年表 | 800–1200 | 一条能看懂的主干曲线 |
| 3 关键节点 | 2400–3600 | 全篇价值所在：每个拐点的前因后果 |
| 4 曲线 | 400–600 + 图 | 用数据证明前面说的起伏 |
| 5 兴衰解剖 | 800–1200 | 从故事里抽出机制 |
| 6 教训 | 500–800 | 3–5 条，可迁移 |
| 7 证据 | 800+ | 可核查 |

## 第 1 段：现状侧写

结构固定为「判词 → 官方三数 → 社区三声 → 商业处境」。

```markdown
> **判词**：它没有死，但也回不到 2021–2024 年的位置了——2026 年的永劫无间，是一个靠赛事与联动维持声量、靠核心动作玩家维持日活的长线产品。

### 1.1 官方口径：还在运营，且仍有位置
- 在线：〔E1〕〔E2〕——区分 Steam 与全平台口径。
- 商业：财报里怎么提它〔E3〕；手游流水/榜单〔E4〕。
- 版本节奏：最近 12 个月出了什么大版本〔E5〕。

### 1.2 社区口径：夸什么、骂什么
- 长期评价：Steam 总评/近期、TapTap 评分〔E6〕。
- 高频抱怨：匹配、平衡、外挂、皮肤定价、优化——每条配一个具体帖子/评测〔E7〕。
- 仍然留下的理由：动作系统没有替代品、亲友队、赛事〔E8〕。

### 1.3 一句话说清商业处境
买断/免费/内购/联动/赛事，各自在收入里扮演什么角色（能证实的写，不能的标推断）。
```

要求：官方与社区必须都有，且**不许用官方数据去反驳玩家感受**——两者可以同时为真。

## 第 2 段：生平年表

用 `timeline` 块，5–8 个阶段。每阶段只写「时间 + 一句话事件 + 一个数据动作」。

```chart 不要用；用下面这个：
```timeline
{"stages":[
  {"period":"2019–2021.07","title":"立项到公测","desc":"24 工作室从流星 IP 转向武侠吃鸡，2021.07 国服不删档。","tone":"normal"},
  {"period":"2021.08","title":"上线即爆","desc":"Steam 全球上线，首周峰值 12.9 万，11 月销量 600 万。","tone":"peak"},
  {"period":"2022.04–07","title":"第一个长草期","desc":"版本空窗叠加误封争议，Steam 峰值跌到 10.7 万。","tone":"trough"},
  {"period":"2023.07","title":"买断转免费","desc":"PS5 同步上线，峰值回到 26.4 万。","tone":"turn"}
]}
```

写法：阶段名用「人话」而不是版本号；desc 不超过 45 字；tone 只标真正的峰谷/转折。

## 第 3 段：关键节点

每个节点一个 `node` 块。字段固定，顺序固定。

```node
{
  "date":"2023.07.14",
  "type":"turn",
  "title":"买断转免费：用 700 亿金块买第二次生命",
  "verdict":"上线两周年前夜取消 98/168/248 元门票，按原价返还金块；短期被骂「背刺」，三个月后全球玩家从 2000 万涨到 4000 万。",
  "metrics":[{"label":"Steam 峰值","value":"26.4 万"},{"label":"累计玩家","value":"4000 万"}],
  "before":"2023 上半年 Steam 峰值在 10 万–15 万区间，买断制把新增卡在 98 元门槛；同期《无畏契约》国服 7.12 上线，分流射击竞技用户。",
  "during":"发布会后官网被挤爆，Steam 热销榜第 2/第 4；老玩家按版本返 1960/3360/4960 金块，送绝版皮肤与 10 个宝箱，舆论从「退钱」转向「真香」。",
  "after":"7 月 Steam 峰值 26.4 万，10 月官宣 4000 万玩家；但免费也把外挂与低质量对局放进来，为 2024 年后的口碑下滑埋线。",
  "evidence":"E9,E10,E11,E12"
}
```

四问的写法：

- **before** 写「此前 3–6 个月」，必须出现具体版本/竞品/数据，不写「此前表现一般」。
- **during** 写「官方做了什么 + 数据/舆论怎么反应」，官方原话可短引。
- **after** 写「3–6 个月后的可验证结果」，不写「影响深远」。
- **verdict** 是一句人话判断，允许有观点，但必须被下面三栏支撑。

type 取值：`peak` 波峰、`trough` 波谷、`turn` 转折、`event` 事件。

## 第 4 段：起伏曲线

`chart` 块 JSON 规格：

```chart
{
  "id":"steam_ccu",
  "title":"Steam 同时在线峰值：三次起落",
  "unit":"万人",
  "kind":"line",
  "x":["2021-08","2021-09","2021-10","2021-11","2021-12","2022-01"],
  "series":[{"name":"月峰值","values":[12.9,16.1,14.1,15.4,18.7,13.9]}],
  "annotations":[{"at":"2023-07","label":"转免费"}],
  "caption":"三次台阶：上线、转免、三角洲冲击；2022 年长草期是第一个谷。",
  "ev":"E5/E6",
  "source":"SteamDB / CSGODT",
  "note":"月度峰值；缺月留白，不插值"
}
```

规则：

- 一张图只讲一个结论，标题就写结论。
- 不同口径不叠图；要对比就分两张或双轴并注明。
- 缺数据用 `null` 留白，不补 0、不插值。
- caption 必须写「这张图证明了什么」+ 证据编号。
- 图 2–4 张：在线/活跃 ≥1，商业/口碑 ≥1。

## 第 5 段：兴衰解剖

```markdown
| 因子 | 具体表现 | 作用方向 | 证据 | 置信度 |
|---|---|---|---|---|
| 内容供给节奏 | 2022 上半年只有 1 个新英雄，赛季空窗 4 个月 | 拉低留存 | E13/E14 | 高 |
| 付费模型 | 买断 98 元挡住下沉用户；转免后 ARPU 靠外观 | 先限增长、后放量 | E9/E15 | 高 |
| 竞品分流 | 2024.09 三角洲上线，次月在线腰斩 | 直接分流 | E16 | 中（媒体复盘） |
| 平台/政策 | 版号、防沉迷、亚运入项 | 双向 | E17/E18 | 中 |
```

要求：至少 5 行；「作用方向」写「拉高/拉低/双向」；「置信度」写高/中/低；相关不等于因果，媒体复盘标中。

## 第 6 段：可迁移的教训

每条用「现象 → 机制 → 边界」三段式，3–5 条：

```markdown
1. **买断制给的是「身份」，也是「门槛」**。永劫前两年靠 98 元筛出了高黏性、低外挂的社区，但也把下沉用户挡在门外；转免换来了规模，代价是治理成本。适用于「内容型竞技 + 强社交」产品，不适用于靠买断回本的单机。
```

不要写「要重视玩家体验」「要持续更新」这类正确的废话。

## 句式对照

| 别这么写 | 改成这样 |
|---|---|
| 随着时间的推移，游戏逐渐走向下坡路 | 2024 年 9 月三角洲上线后，Steam 峰值从 30 万级跌到 11 万，持续了六个月 |
| 官方积极听取玩家意见 | 官方在 7 月 14 日公告里承认匹配问题，并给出「按数据匹配」的调整时间表〔E12〕 |
| 玩家普遍不满 | 最近 30 天 Steam 简中评测 59% 好评，差评集中在匹配与外挂〔E7〕 |
| 这款游戏凉了 | 它从「全民爆款」退回了「核心玩家产品」：日活只剩峰值的两成，但赛事与联动仍在正常投入〔E1〕〔E18〕 |

## 常见失败案例

1. **年表写成更新日志**：每个赛季都列，读者看不到起伏。→ 只留数据/模式/平台/竞品四类拐点。
2. **只有官方口径**：财报说「人气颇高」，正文就写「依旧火爆」。→ 必须配平台数据与社区声音。
3. **拿 Steam 数据代表全平台**：官服与手游玩家被凭空消失。→ 标口径，必要时两张图。
4. **把相关当因果**：竞品上线当月数据跌，就断言「被竞品打崩」。→ 看前后 3 个月趋势，标推断与置信度。
5. **节点没有「之后」**：只写事件，不写结果。→ 每个节点必须有可验证的后效。
6. **用情绪词代替数据**：封神、暴死、yyds。→ 换成数字与场景。
