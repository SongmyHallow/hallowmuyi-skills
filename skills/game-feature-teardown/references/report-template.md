## 图表与截图规范

- 截图 2–5 张，标来源与证据编号；用 `<figure>` + `<figcaption>`，图注写“这一屏说明什么”。
- 数据图 1–3 张：能画阶梯/区间/占比就画；标题写结论，坐标带单位，图注标口径与是否推导。
- 无可信数字不画数据图；流程与结构用 SVG/HTML 图，不用截图代替。
- 本地图放 `assets/`，构建时自动内联；浅色主题需要图表的 `_light` 版本（`LIGHT=1 python3 make_charts.py` 可生成）。
- 证据表来源列用短标签超链接，不贴整条 URL（长 URL 会把表格挤成竖排字）。

## 硬性要求

- 事实带 `〔E1〕`，推断写 `〔推断，依据：…〕` + 置信度；禁“显然”“业内通常”。
- 不写无来源数字；产品名首次出现写全称 + 平台/上线时间。
- 交付前 `check_report.py` 通过，再 `build_html.py` 生成 HTML。
