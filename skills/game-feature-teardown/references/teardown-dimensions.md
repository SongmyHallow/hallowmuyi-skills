# 拆解维度清单

按功能类型选维度，不要全填。逐条回答，答不上标 `〔待验证〕`，不靠感觉补。涉及匹配、段位、身份、分流、观战时直接跳到第 6 节。

## 0. 系统位置图（先画再写）

第一份交付物是图，不是字。四类节点：**上游（谁给资格）→ 本功能（当前环节）→ 下游产出（给出什么）→ 旁挂系统（跟谁互相影响）**。

- 节点 ≤10，每个写“系统名 + 一句话作用”；箭头标注语义（解锁/产出/导流/约束）。
- 标出在进度链上的位置：第几层进度、赛季内还是跨赛季、能否重复。
- 玩家路径能一眼读出：从哪进、成本多少、出来拿到什么。
- 落地：HTML 内联 SVG（构建器原样保留），Markdown 可用 mermaid，最差用缩进树 + 箭头。
- 位置图 ≠ 流程图：位置讲系统咬合，流程讲玩家点几下，两张都要。

## 通用骨架

1. 定位：挂哪个大系统，上游给什么、下游吃什么。
2. 对象：服务哪类玩家（新手/中R/大R/回流/社交），什么阶段解锁。
3. 目标：想让玩家产生什么行为与情绪。
4. 结构：入口 → 主界面 → 子界面 → 结算，几步。
5. 规则：能做什么、不能做什么、限制是什么。
6. 反馈：每次操作的即时反馈（数值/动效/音效/文案）。
7. 代价：失败或放弃付出什么（时间/资源/进度）。
8. 替代：不做这个损失什么，有没有绕过路径。

## 1. 玩法机制与核心循环

- 核心循环：`动作 → 反馈 → 奖励 → 再投入`，一句话 + 闭环图。
- 目标分层：单局 / 当日 / 长线，是否互相牵引。
- 决策点：一局几个关键选择，每个是否有真实代价。
- 失败设计：条件、代价、重来成本。
- 节奏：单局时长、难度曲线、跃迁点。
- 爽点密度：多久一次正反馈，最大爽点在何时。
- 外围接口：产出/消耗哪些资源，是否导流养成、社交、付费。
- 限速与反挂机：体力、次数、冷却、自动战斗。

## 2. 数值与经济

- 属性与公式：只写能反推的部分，附推导。
- 成长曲线：投入产出比、边际递减、拐点。
- 资源分类：硬通货/软通货/养成材料/体力/社交货币。
- 产出源 vs 消耗池：从哪来、到哪去、每日上限。
- 卡点：从哪一步缺资源，意图是制造付费还是社交。
- 概率：基础概率、保底、伪随机体验。
- 追赶与膨胀：版本涨幅、回流追赶通道。
- 评分/战力：如何把养成翻译成可比数字。

## 3. UI 与体验路径

- 入口层级：几次点击，有无红点/动效/气泡。
- 信息架构：一屏的主次、默认焦点、密度。
- 操作步数：完成核心行为几步。
- 反馈链：点击、数值跳动、动效、音效、震动、飘字。
- 边界态：空/加载/失败/上限/断网。
- 引导：强制引导长度、渐进提示。
- 理解成本：不看攻略能否 30 秒明白。

## 4. 商业化

- 付费点：位置、触发时机、价格锚点、替代货币。
- 免费/付费差：跳过时间、随机、惩罚还是内容量。
- 商品结构：首充、月卡、通行证、基金、礼包阶梯。
- 漏斗：曝光 → 点击 → 详情 → 支付，摩擦在哪。
- 付费墙：第一次“不充就过不去”在哪。
- 风险：pay-to-win 强度、抽卡透明度、未成年保护观感。

## 5. 新手与留存

- 新手流程：时长、强制/可选、前 10 分钟解锁清单。
- 首日目标：D1 拿到什么，“明天再来”的钩子。
- 日常/周常：结构、单日时间成本、奖励占比。
- 活动节奏：版本/赛季/节日密度与形式。
- 回流：回归奖励、追赶、社交召回。
- 关系绑定：公会/好友/排行/师徒的拉动强度。

## 6. 匹配、段位与身份

- 触发条件：什么段位/身份/人数进入；能否关闭。
- 分流结构：混排 / 分池 / 可选，各自代价（时长、割裂、污染）。
- 决策窗口：多久、几个选项、信息是否现场可见。
- 风险收益：每个选项“赢/输/不操作”各得到失去什么。
- 身份外显：标识、数字、入场表演，曝光给谁。
- 兜底规则：超时、断线、未选的默认倾向谁。
- 反滥用闸：亲密度、等级差、分数上限、次数、开关，数清几道。
- 进度重置：最高段位可否重复、重置后保留什么。
- 长线标的：称号/冠数/排名，台阶怎么设，第几档疲劳。
- 观战押注：旁观者能做什么，是否影响对局。
